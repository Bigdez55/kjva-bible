## Verdict (honest)

**This benchmark proves the runtime engine works at byte level with determinism and a measurable BPB on in-domain text.** It does NOT prove:
- Frontier-comparable broad-knowledge capability (§2 not run)
- Hallucination/grounding properties (§3.1–§3.4 not run)
- Injection resistance via R1_PER (§3.6 not run)
- Efficient under multi-process (§4.6 only in-process)
- BPB competitive with frontier on a fair shared-bytes protocol (§10 not run)

To close those gaps, the artifacts that need to be added to this repo are:
1. Evaluation sets (MMLU/GSM8K/ARC/etc. — or smaller equivalents)
2. A retriever + grounded corpus binding (for §3.1–§3.4)
3. R1_PER opcode encoder/decoder (for §3.6, §7)
4. Adversarial / NIAH / RULER sets (for §6, §8)
5. Alternate quantization variants of model.gguf (for §4.7)
6. Frontier API access wired with normalized prompts (for §10)
7. Training corpus hash on disk for contamination audit (for §11)
