# Evaluation Workspace

This directory stores validation reports for retraining runs.

Current tracked evaluation group:

- `kjv_tokenless_v1/` - retrieval validation and omni training plan.

Generated model-evaluation files such as `kjv_bpe_v1_20m.eval.json`,
`kjv_byte_v1_20m.eval.json`, and `selection_report.json` are produced during
the evaluate and publish stages.
